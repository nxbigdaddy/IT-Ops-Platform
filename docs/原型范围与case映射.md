# 原型范围与验收清单映射

> 日期：2026-10-10。本表把当前原型的实际路由映射到 [部门原型验收清单](<部门原型验收清单.md>) 的 case ID，用于向使用部门说明“本批次覆盖哪些脚本、哪些排除”。
> 映射由 `scripts/prototype-scope-map.mjs` 校验：路由必须与 `src/frontend/src/nav.ts` 完全一致，引用的 case ID 必须真实存在于验收清单；不一致即测试失败。
> **本表不改变任何实现状态**：所有页面仍为模拟数据，未接真实设备、数据库、模型或生产认证。
