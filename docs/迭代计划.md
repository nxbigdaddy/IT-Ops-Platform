## 交付策略

1. **原型先行**：提供可点击、可筛选、可编辑模拟配置、可记录反馈的中文 Web 工作台，而非静态页面截图。
2. **开发并行**：前端、后端基础、扩展设计各自独占文件，主线负责联调、检查与 Git 提交。
3. **逐轮闭环**：需求→实施→构建/自动测试→问题修复→文档与更新日志→本地提交→下一轮。
4. **避免假验收**：自动测试只能形成技术验收记录；使用部门认可需真实反馈，不用模拟反馈冒充用户认可。
5. **默认安全**：Demo 不执行真实运维操作，所有模型输出、连接测试和状态均标记模拟；原型不保存真实密钥。
