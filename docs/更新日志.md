# 更新日志

本文记录项目每次有实际交付的变更；设计决策、代码、配置、文档和验证结果均在记录范围内。

## 记录规则

1. 每次变更与对应代码/文档在同一次本地 Git 提交中提交，不仅在聊天里记录。
2. 条目包含日期、变更范围、实际新增/修改、验证结果、未完成事项及必要风险。
3. 区分“方案设计”“开发完成”“验证通过”，不得把计划写成实现成果。
4. 不记录密码、令牌、私钥或完整的带凭据连接字符串。
5. 提交编号通过 `git log --oneline` 查询，不在待提交条目内填写其自身提交哈希。
6. 仅重大阶段交付使用发布版本号；目前是初始化基线，不表示业务功能发布。
